配置流程

配置是本页重点。按下列顺序操作，可把菜市场(Texon) 订阅落到常用加速器客户端，避免只收藏官网却无法上网。

第一步：确认套餐与订阅形态

对照流量、设备与是否需要 IPLC。开通后你会得到订阅 URL（Clash / 通用格式以实际面板为准）。不要把链接发到公开群组。

第二步：准备客户端

iOS 常用 Shadowrocket、Stash；Android 常用 Clash Meta for Android；桌面常用 Clash Verge、FlClash 或 v2rayN。请从应用商店或项目发布页获取，菜市场(Texon) 官网不托管安装包。

第三步：导入订阅

在客户端选择「从 URL 导入 / 新建订阅」，粘贴链接并更新。若支持 UA 或流量信息展示，可打开以便核对剩余流量。更新失败时检查系统时间、TLS 与是否被本地拦截。

第四步：选择节点与模式

先测延迟，再测解锁。浏览用负载较轻的普通节点，游戏切 IPLC，流媒体选标注原生的入口。开启系统代理或 TUN / 增强模式，按需打开规则分流。

第五步：规则与分流

国内域名直连、国外走代理是默认策略。团队版可按部门做定制路由。规则更新后若个别 App 异常，把该 App 加入绕过列表再测。

配置时注意

  • 同一订阅可在多台设备导入，但同时在线受套餐设备数限制。
  • 流量以服务端计量为准，月度重置；下载大文件请预估余量。
  • 若节点全红，先更新订阅再切换协议或更换网络（蜂窝 / Wi-Fi）。

常见问题

菜市场(Texon) 是 VPN 还是机场订阅？

对外可以理解为网络加速与梯子用途，交付形式上是机场订阅：一份链接给多款客户端用，节点和规则由服务端更新。比单一 App 内置线路更灵活，也更依赖你正确完成导入。

怎样完成客户端下载后的第一次上网？

安装可信客户端 → 粘贴订阅 URL 并更新 → 选延迟较低节点 → 打开系统代理或 TUN。旗舰版用户可优先尝试 IPLC 与原生流媒体节点。若完全无网，先关闭再开启配置，并检查是否有其他 VPN 抢占通道。

三个套餐该怎么选？

轻度浏览与基础流媒体选基础版（100GB / 3 设备）。需要更好解锁、游戏线路和优先工单选旗舰版。多人共用、要高带宽与定制路由选团队版。年付适合已经跑通配置、准备长期用的用户。

设备数和流量超了会怎样？

同时在线超过套餐上限时，新设备可能无法握手。流量用尽后需等待重置或升级档位。建议在客户端查看剩余流量，大文件下载安排在余量充足时进行。

官方身份如何辨认？下载地址在哪？

以本站套餐名称、配置流程和工单入口为准。菜市场(Texon) 不提供来路不明的「一键包」。客户端请走各软件官方或系统商店；订阅仅在你的用户中心复制。遇索要远程桌面或代装的，应拒绝。

连接失败时如何自查？

核对系统时间、更新订阅、更换节点与网络。公司网或校园网可能干扰 UDP，可改 TCP 或另一端口。仍失败时，旗舰与团队用户走优先工单，说明客户端名称、系统版本与报错原文。
